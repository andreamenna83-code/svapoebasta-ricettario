# Svapo&Basta – Guida alle diluizioni

Piccola web app statica, pronta per GitHub Pages.

## Avvio in locale
Apri `index.html` nel browser.

## Pubblicazione su GitHub Pages
1. Crea un repository GitHub (ad esempio `svapoebasta-diluizioni`).
2. Carica `index.html`, `README.md` e la cartella `assets`.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona `main` e `/ (root)`, poi salva.

La web app usa le immagini originali fornite come sorgenti e non modifica i dosaggi.
